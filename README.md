# M STORE

متجر إلكتروني Dark UI مبني بـ HTML + CSS + JavaScript فقط.

## التشغيل
1. فك الضغط.
2. افتح `index.html` في المتصفح.

## التعديل
- المنتجات والأسعار: `script.js`
- التصميم والألوان: `style.css`
- النصوص والأقسام: `index.html`

## مهم قبل النشر الحقيقي
هذا المشروع Front-End تجريبي. لإطلاق متجر حقيقي ستحتاج Backend وقاعدة بيانات، ونظام طلبات/دفع وشحن وحماية.
